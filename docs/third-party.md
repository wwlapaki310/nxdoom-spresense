# 他から持ってきたものと、ライセンス

このリポジトリは、**自作の文書とスクリプトだけ**を置き、他のものは、**コピーせずに、リンクで参照**しています。理由は、それぞれ、ライセンスが違うためです。

| 対象 | ライセンス (わかる範囲) | このリポジトリでの扱い |
|---|---|---|
| このリポジトリの、自作の文書とスクリプト | Apache-2.0 | 置いている |
| NuttX (`apache/nuttx`、`apache/nuttx-apps`) の、Apache-2.0 の部分 | Apache-2.0 | 置かない。リンクだけ |
| **NXDoom (`apps/games/NXDoom`)** | **GPLv2** (Chocolate DOOM から派生。ファイルの先頭に、GPL の表記がある) | **置かない。** 本家のコミットを参照する |
| Sony Spresense の SDK (`flash_writer`、`firmware.zip` のローダー) | Sony の規約 (SDK に、利用許諾の文書がある) | **置かない。** https://github.com/sonydevworld/spresense から、入手する |
| WAD (DOOM のデータ。Squashware の1レベル版など) | WAD ごとに、配布の条件が違う | **置かない。** 入手先のリンクだけ |
| ビルドしたファームウェア (`.spk`) | NXDoom (GPL) を含む | **置かない** |
| 他の人の、PR のコメントやレビュー | それぞれの著者の著作物 | **全文は、置かない。** 要約と、コメントへのリンクだけ。短い引用は、出典を付ける |
| CI のログ | GitHub Actions の出力 | **置かない。** 結果の要約だけ |

## 引用について

- 本家の `CONTRIBUTING.md` などは、Apache-2.0 ですが、全文は、載せずに、**リンクと要約**にしています。
- レビューのコメントは、「何を、直してほしいと言われたか」を、**言い換え**て書き、元のコメントへの**リンク**を付けています。

## ライセンスの確認が必要なもの

次の場合は、公開する前に、ライセンスを、確認してください。

- 本家のコード (特に NXDoom) を、このリポジトリに、コピーする。
- 写真や動画に、他の人の著作物が写り込む。
- ファームウェアを、配布する (GPL のソース提供の義務が、生じます)。
