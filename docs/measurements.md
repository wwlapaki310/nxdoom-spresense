# 実機の確認結果

## 動作

- 新しいゲームの開始、前進・後退、左右の回転、撃つ、使う、がすべて効く (WAD は、1レベルだけの Squashware 版)
- #3860 を当てた版 + キー入力 (①) でも、同じように動く。画面切り替えの演出は出ず、止まらない
- ①のコードを、別ファイル (`i_input_uartkbd.c`) に分けた版、字下げを直した版も、実機で、エラーなしで動いた
- 本家の master (nuttx と nuttx-apps) から、ゼロでビルドした `spresense:nxdoom` が、ビルドできることと、`refresh.sh` で差分がないことを確認した
- ドキュメントは、Sphinx で、追加したページが、正しく出る (ビルド全体は、元からあるファイルの警告で、失敗扱いになる。追加した部分とは、無関係)

## フレームレート

ゲーム中は、約 **19〜20 fps** (元の DOOM は、1秒に35回、状態を更新する)。

| 場面 | フレームレート |
|---|---|
| ゲーム中 (立ち止まり) | 約 19 fps |
| ゲーム中 (前進) | 約 19〜20 fps |
| タイトルのデモ | 15〜22 fps (レベルの読み込み直後だけ、6 fps まで下がる) |

**測り方:** 画面を描き替える関数の中で、呼ばれた回数と時刻を数えて、2秒ごとに、1秒あたりの回数を、シリアルに出す一時的なコードを、手元のコピーにだけ入れた。本家のコードには、入れていない。差分は、GPL の NXDoom のファイルに対するものなので、このリポジトリには、置いていない。

## メモリ (参考)

- Spresense の RAM は 1.5 MB。ゲームのコードと変数で、約 0.5 MB を使い、残りが、ヒープになる
- フレームバッファ (ディスプレイ用) が、約 150 KB、ヒープから取られる
- WAD を置くフラッシュ (`/mnt/spif`) は、4 MB (1024 ブロック × 4096 バイト)。標準の shareware 版 (約 4.2 MB) は、入らない
